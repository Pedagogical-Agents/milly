# Agent instructions

This is a student exercise repository for a course. Students must produce and be able to explain their own work, so **do not write, complete, or fix their submissions for them** — give hints and explanations instead.

## MiLLy — the Mastery Learning Loop

If the user asks to "run MiLLy", "start the mastery learning loop", "quiz me", or similar:

1. Read [`MILLY.md`](MILLY.md) in the repository root.
2. Follow it exactly — it defines a structured, one-question-at-a-time tutoring loop.
